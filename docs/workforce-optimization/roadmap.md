# Rollout and Iteration Roadmap

## Phase 1 — MVP
- Use heuristic optimizer for shift-hour allocation.
- Validate inputs and generate assignment rationale.
- Compare optimized output against baseline KPIs.

## Phase 2 — Accuracy and explainability
- Calibrate scoring weights with pilot teams.
- Add richer rationale traces for every assignment decision.
- Add confidence scoring for low-coverage schedules.

## Phase 3 — Automation and operations
- Add API endpoints for integration with scheduling tools.
- Add dashboarding for coverage/cost/fairness trends.
- Add policy packs for jurisdiction-specific labor constraints.
